# Mental Health Text Classification

A machine learning project that classifies mental health-related text into different categories using natural language processing techniques and various classification models.

## Project Overview

This project aims to classify text data into different mental health categories including:
- Anxiety
- Depression
- Bipolar Disorder
- Stress
- Personality Disorder
- Normal Mental Health

The project includes preprocessing, feature engineering, model training, evaluation, and a Streamlit web application for real-time predictions.

## Features

- **Advanced Text Preprocessing**: Comprehensive text cleaning and normalization
- **Feature Engineering**: TF-IDF vectorization with enhanced features
- **Multiple ML Models**: Logistic Regression and Random Forest classifiers
- **Model Optimization**: Hyperparameter tuning and performance optimization
- **Interactive Web App**: Streamlit-based interface for real-time predictions
- **Comprehensive Evaluation**: Detailed model performance metrics and visualizations

## Performance

The models achieve competitive performance on the dataset:
- **Logistic Regression**: ~70-80% accuracy
- **Random Forest**: ~70-80% accuracy

(Note: Performance metrics will vary based on the specific dataset and hyperparameters)
